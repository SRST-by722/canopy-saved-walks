# London CANOPY 8 km optimised viewer

Independent deployment candidate for BoHan Ye's account, based on
[dodgykid101/canopy-saved-walks](https://github.com/dodgykid101/canopy-saved-walks)
at bac8b27f39811918b4530c859139b324285daf8a. The viewer adds faster pedestrian
startup, Bristol-style wind streaks, and on-demand sunlight and flood frame loading.
Original geometry, routes and simulation outputs retain their provenance.
See THIRD_PARTY_NOTICES.md and UPSTREAM_README.md.
